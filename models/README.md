# 3D Spider-Man Models

To use custom rigged Spider-Man models:

1. Download a rigged `.glb` model for the suit:
   - `models/tom.glb` (Homecoming suit)
   - `models/tobey.glb` (Classic 2002 suit)
   - `models/andrew.glb` (Amazing suit)
2. Add animation clips named:
   - `idle`
   - `run`
   - `swing`
   - `fall`
3. If any model is missing, the game automatically uses the built-in procedural athletic Spider-Man model.
